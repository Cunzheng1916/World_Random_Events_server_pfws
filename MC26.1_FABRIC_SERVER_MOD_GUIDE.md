### 6.1 所有可用事件及 import

```java
// 玩家攻击实体
import net.fabricmc.fabric.api.event.player.AttackEntityCallback;
AttackEntityCallback.EVENT.register((Player player, Level world, InteractionHand hand,
        Entity target, EntityHitResult hitResult) -> {
    if (world.isClientSide()) return InteractionResult.PASS;
    if (!(player instanceof ServerPlayer serverPlayer)) return InteractionResult.PASS;
    // ... 服务端逻辑
    return InteractionResult.PASS;
});

// 生物受到伤害前 (可拦截)
import net.fabricmc.fabric.api.entity.event.v1.ServerLivingEntityEvents;
ServerLivingEntityEvents.ALLOW_DAMAGE.register((entity, source, amount) -> {
    // 返回 false 可阻止伤害
    return true;
});

// 生物受到伤害后
ServerLivingEntityEvents.AFTER_DAMAGE.register((entity, source, baseDamage, taken, blocked) -> {
    // taken = 实际受到的伤害, blocked = 被阻挡的伤害
});

// 实体卸载 (玩家死亡/退出)
import net.fabricmc.fabric.api.event.lifecycle.v1.ServerEntityEvents;
ServerEntityEvents.ENTITY_UNLOAD.register((entity, world) -> {
    if (entity instanceof ServerPlayer player && player.isDeadOrDying()) {
        // 清理数据
    }
});

// 服务器 tick 结束
import net.fabricmc.fabric.api.event.lifecycle.v1.ServerTickEvents;
ServerTickEvents.END_SERVER_TICK.register(server -> {
    for (ServerPlayer player : server.getPlayerList().getPlayers()) {
        // 遍历在线玩家
    }
});

// 玩家挖掘方块后
import net.fabricmc.fabric.api.event.player.PlayerBlockBreakEvents;
PlayerBlockBreakEvents.AFTER.register((world, player, pos, state, blockEntity) -> {
    if (world.isClientSide()) return;
    if (!(player instanceof ServerPlayer sp)) return;
    // ...
});

// 玩家使用方块 (右键)
import net.fabricmc.fabric.api.event.player.UseBlockCallback;
UseBlockCallback.EVENT.register((Player player, Level level, InteractionHand hand,
        BlockHitResult hitResult) -> {
    if (level.isClientSide()) return InteractionResult.PASS;
    // ...
    return InteractionResult.PASS;
});

// 玩家进服
import net.fabricmc.fabric.api.networking.v1.ServerPlayConnectionEvents;
ServerPlayConnectionEvents.JOIN.register((handler, sender, server) -> {
    ServerPlayer player = handler.getPlayer();
    server.execute(() -> { /* 延迟执行，确保玩家完全加载 */ });
});

// 玩家退服
ServerPlayConnectionEvents.DISCONNECT.register((handler, server) -> {
    // 清理玩家数据
});

// 服务器停止
import net.fabricmc.fabric.api.event.lifecycle.v1.ServerLifecycleEvents;
ServerLifecycleEvents.SERVER_STOPPING.register(server -> {
    // 保存数据、清理缓存
});
```

### 6.2 关键模式

- **客户端检查**: 所有事件回调必须 `if (world.isClientSide()) return;`
- **类型窄化**: 用 `instanceof ServerPlayer sp` 模式匹配窄化
- **InteractionResult.PASS**: 不阻止其他 mod 处理

## 7. 命令注册 (Brigadier)

```java
import net.fabricmc.fabric.api.command.v2.CommandRegistrationCallback;
import com.mojang.brigadier.CommandDispatcher;
import net.minecraft.commands.CommandSourceStack;
import net.minecraft.commands.Commands;
import net.minecraft.commands.arguments.EntityArgument;
import com.mojang.brigadier.arguments.StringArgumentType;
import com.mojang.brigadier.arguments.IntegerArgumentType;

CommandRegistrationCallback.EVENT.register((dispatcher, registryAccess, environment) -> {
    dispatcher.register(Commands.literal("mycmd")
        .requires(Commands.hasPermission(Commands.LEVEL_GAMEMASTERS))  // 2 = OP
        .then(Commands.argument("target", EntityArgument.player())
            .executes(ctx -> {
                ServerPlayer target = EntityArgument.getPlayer(ctx, "target");
                ctx.getSource().sendSuccess(() -> Component.literal("OK"), false);
                return 1;
            })
        )
    );
});
```

### 命令权限等级

| 常量 | 值 | 含义 |
|------|---|------|
| `Commands.LEVEL_ALL` | 0 | 所有人 |
| `Commands.LEVEL_MODERATORS` | 1 | 可绕过出生点保护 |
| `Commands.LEVEL_GAMEMASTERS` | 2 | OP / 命令方块 |
| `Commands.LEVEL_ADMINS` | 3 | 管理员 / 控制台 |
| `Commands.LEVEL_OWNERS` | 4 | 服主 |

### 返回值约定

- `1` = 命令执行成功
- `0` = 命令执行失败

### 发送消息


## 8. Data Components API (替代旧 NBT 系统)

### 8.1 读取自定义数据

```java
import net.minecraft.core.component.DataComponents;
import net.minecraft.world.item.ItemStack;
import net.minecraft.world.item.component.CustomData;
import net.minecraft.nbt.CompoundTag;

// 获取 NBT (安全)
CustomData data = stack.getOrDefault(DataComponents.CUSTOM_DATA, CustomData.EMPTY);
if (data.isEmpty()) return defaultValue;
CompoundTag nbt = data.copyTag();

// 读取值
int val = nbt.getIntOr("my_key", 0);         // 安全读取，不存在返回默认值
String s = nbt.getStringOr("my_str", "");

// 读取列表
ListTag list = nbt.getList("my_list").orElse(null);
```

### 8.2 写入自定义数据

```java
// CustomData.update 是幂等的安全写入方式
CustomData.update(DataComponents.CUSTOM_DATA, stack, compoundTag -> {
    compoundTag.remove("old_key");  // 先删除旧的
    compoundTag.putInt("my_key", value);
    compoundTag.putString("my_str", "text");
    
    // 写入列表
    ListTag list = new ListTag();
    CompoundTag item = new CompoundTag();
    item.putString("id", "something");
    item.putInt("level", 3);
    list.add(item);
    compoundTag.put("my_list", list);
});
```

### 8.3 读取列表 (ListTag 遍历)

```java
ListTag list = nbt.getList("traits").orElse(null);
if (list == null) return Collections.emptyList();
for (int i = 0; i < list.size(); i++) {
    CompoundTag tag = list.getCompound(i).orElse(null);
    if (tag == null) continue;
    String id = tag.getStringOr("id", "");
    int level = tag.getIntOr("level", 0);
}
```

### 8.4 LORE 描述 (ItemLore)

```java
import net.minecraft.world.item.component.ItemLore;
import net.minecraft.network.chat.Component;
import net.minecraft.ChatFormatting;

// 获取现有 lore
ItemLore currentLore = stack.getOrDefault(DataComponents.LORE, ItemLore.EMPTY);
List<Component> lines = new ArrayList<>(currentLore.lines());

// 追加描述
lines.add(Component.literal("⚔ 标题").withStyle(ChatFormatting.GOLD, ChatFormatting.BOLD));
lines.add(Component.empty()
    .append(Component.literal("  ◆ ").withStyle(ChatFormatting.DARK_GRAY))
    .append(Component.literal("内容").withStyle(ChatFormatting.GOLD)));

// 写入
stack.set(DataComponents.LORE, new ItemLore(lines));

// 移除 lore
stack.remove(DataComponents.LORE);
```

### 8.5 重要: `copyTag()` vs `copyTag()` 方法名

- `CustomData` 的复制方法在 MC 26.1 中可能是 `copyTag()` (注意大小写)
- 如编译报错方法不存在，尝试 `getUnsafe()` 或直接读取

## 12. Mixin 注入

```java
package com.example.mixin;

import net.minecraft.world.level.block.DispenserBlock;
import net.minecraft.world.level.block.state.BlockState;
import net.minecraft.world.level.Level;
import net.minecraft.core.BlockPos;
import org.spongepowered.asm.mixin.Mixin;
import org.spongepowered.asm.mixin.injection.At;
import org.spongepowered.asm.mixin.injection.Inject;
import org.spongepowered.asm.mixin.injection.callback.CallbackInfo;

@Mixin(DispenserBlock.class)
public class DispenserBlockMixin {

    // 在方法头部注入，可取消
    @Inject(method = "neighborChanged", at = @At("HEAD"), cancellable = true)
    private void onNeighborChanged(BlockState state, Level level, BlockPos pos,
                                    Block neighborBlock, BlockPos neighborPos,
                                    boolean movedByPiston, CallbackInfo ci) {
        if (level.isClientSide()) return;
        if (shouldCancel(level, pos)) {
            ci.cancel();  // 取消原方法执行
        }
    }
}
```

### Mixin 回调类型

| 类型 | 用途 |
|------|------|
| `CallbackInfo` | void 方法 |
| `CallbackInfoReturnable<T>` | 有返回值的方法，可用 `cir.setReturnValue()` 修改 |

### ItemStack Mixin 特殊模式

```java
@Mixin(ItemStack.class)
public class ItemStackMixin {
    // 要获取 this (ItemStack 实例)
    ItemStack self = (ItemStack) (Object) this;
}
```

### @ModifyVariable 修改方法参数

```java
@ModifyVariable(method = "hurtAndBreak", at = @At("HEAD"), argsOnly = true)

    // 修改 amount 参数的值
```

```java
import com.google.gson.Gson;
import com.google.gson.GsonBuilder;
import com.google.gson.annotations.SerializedName;
import net.fabricmc.loader.api.FabricLoader;
import java.nio.file.Files;
import java.nio.file.Path;

// 配置类
public class TraitConfig {
    @SerializedName("enable_feature")
    private boolean enableFeature = true;
    
    @SerializedName("my_list")
    private List<String> myList = List.of("a", "b");
    
    // getters / setters
}

// 读写操作
public class ConfigStorage {
    private static final Gson GSON = new GsonBuilder().setPrettyPrinting().create();
    private final Path configPath;

    public ConfigStorage() {
        Path configDir = FabricLoader.getInstance().getConfigDir().resolve("modid");
        this.configPath = configDir.resolve("config.json");
    }

    public TraitConfig loadConfig() {
        if (Files.exists(configPath)) {
            try {
                String json = Files.readString(configPath);
                return GSON.fromJson(json, TraitConfig.class);
            } catch (IOException e) { /* fallback */ }
        }
        return new TraitConfig(); // 默认配置
    }

    public void saveConfig(TraitConfig cfg) {
        try {
            Files.createDirectories(configPath.getParent());
            Files.writeString(configPath, GSON.toJson(cfg));
        } catch (IOException e) { /* log error */ }
    }
}
```

## 15. 纯服务端检查清单

在提交代码前，确认以下事项:

- [ ] `fabric.mod.json` 中 `"environment": "server"`
- [ ] `fabric.mod.json` 中无 `"client"` entrypoint
- [ ] `modid.mixins.json` 只用 `"mixins"` 键，无 `"client"` 键
- [ ] 所有 `@Mixin` 目标类都是服务端存在的类
- [ ] 无任何 `net.minecraft.client.*` 导入
- [ ] 所有事件回调都有 `world.isClientSide()` 守卫
- [ ] 发送消息用 `Component.literal()` 而非 `Text.literal()`
- [ ] 伤害用 `hurtServer()` 而非 `hurt(DamageSource, float)`
- [ ] 遍历背包用 `getContainerSize()` + `getItem(i)` 而非 `.items`
- [ ] NBT 操作用 `DataComponents.CUSTOM_DATA` + `CustomData` 而非旧 `getOrCreateTag()`
- [ ] 编译无 `deprecation` 警告

## 17. 已知陷阱与避坑指南

1. **`CompoundTag.getList()` 返回 `Optional<ListTag>`** — 必须 `.orElse(null)` 处理，不能直接当 ListTag 用
2. **`CompoundTag.getCompound()` 返回 `Optional<CompoundTag>`** — 同上
3. **`getIntOr()` / `getStringOr()`** — MC 26.1 新 API，比旧 `getInt()` + 默认值安全
4. **`Player.getInventory().items` 是 private** — 必须用 `getContainerSize()` + `getItem(i)`
5. **`Math.clamp()`** — Java 25 新方法，替代 `Mth.clamp()`
6. **不要删除 `CraftingResultSlotMixin.java`** — 即使空类也需要保留，否则 mixin 配置报错
7. **`CustomData.copyTag()` 方法名** — 确认是 `copyTag()` 还是其他名称
8. **`sendSystemMessage()`** — 在 MC 26.1 中确认用 `Component` 还是 `Text`
9. **`ItemStack.getItem().toString()`** — 不是可靠方式获取注册ID，仅用于关键词匹配
10. **`Commands.hasPermission()`** — `Commands` 类非 `CommandManager`
11. yarn在新版本我的世界已经被弃用了，请使用mojang maps的api编写项目，更多详情请查看https://fabricmc.net/2026/03/14/261.html
